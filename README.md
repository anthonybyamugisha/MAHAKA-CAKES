# MAHACA Sweet Cakes - website

BUC3106 E-Commerce Capstone Project, MUBS Jinja Campus.

This folder is the finished website. It is plain HTML and CSS: no frameworks, no
JavaScript, nothing to install. Every page uses the same `style.css`.

## Files

| File | What it is |
|---|---|
| `index.html` | Home page: heading, one sentence about the business, three reasons to choose us, featured cakes, how to order |
| `products.html` | All eight cakes and prices, in three collections |
| `about.html` | The story behind the name MAHACA, values and founders |
| `pay.html` | How to Pay and Order: four payment methods, payment confirmation, refund rule |
| `policies.html` | Delivery, returns, privacy notice, terms, honest claims |
| `style.css` | All the design for every page (colours, fonts, layout) |
| `images/` | Logo and photos. The current images are placeholders - replace them. |

## See the site on your computer

1. Open this folder in File Explorer.
2. Double-click `index.html`. It opens in your browser.
3. Click through every page and check the menu works.
4. To test the phone view, press `F12`, then click the phone icon at the top of the
   developer tools.

If the page shows plain black text with no colours, `style.css` is not in the same
folder as the HTML files. If images are missing, check the names in `images/` match
exactly, in lower case.

## Put it online with GitHub Pages (free)

1. Sign in to github.com with the **group email**.
2. Click **+** (top right) then **New repository**.
3. Name it `mahaca-sweet-cakes`, choose **Public**, click **Create repository**.
4. Click **Add file** then **Upload files**.
5. Open this folder, select **the files and the images folder inside it** (not the
   folder itself), and drag them into the browser window.
6. Click **Commit changes**.
7. Click **Settings**, then **Pages** in the left menu.
8. Under **Build and deployment**, set Source to **Deploy from a branch**, branch
   **main**, folder **/ (root)**, then click **Save**.
9. Wait two or three minutes and refresh. The live address appears at the top of
   that page. It starts with `https`, which means it is secure.

The address will look like `https://<group-account>.github.io/mahaca-sweet-cakes/`.

## To change something later

Edit the file, then upload the new version with the same name using
**Add file > Upload files**. GitHub replaces the old file. Refresh the live page.
